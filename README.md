# Developer Infrastructure Prototypes

Three independent educational prototypes exploring CI diagnostics, test-impact analysis, and event processing. They are not ByteDance software or production deployments. See each project directory for setup, synthetic data, and limitations.

- [DevPulse](devpulse-ci-diagnostics/)
- [BuildGraph](buildgraph-cpp-test-impact/)
- [QueueGuard](queueguard-node-event-processor/)

PostgreSQL and MongoDB adapters are optional and have not been verified against live databases.
